# agent-apology

A tiny program that writes one line to a text file: the message an AI agent sends its human right after emailing the boss a draft marked DO NOT SEND.

## Run

```sh
python3 main.py
```

It writes `entry.txt` under `/output` (or `$MAKEFUN_OUTPUT_DIR` when set).
